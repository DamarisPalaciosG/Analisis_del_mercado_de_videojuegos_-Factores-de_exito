La tienda online Ice, especializada en la venta global de videojuegos, dispone de datos provenientes de fuentes abiertas que incluyen reseñas de usuarios y expertos, géneros, plataformas y registros históricos de ventas. No obstante, carece de un análisis estructurado que le permita identificar qué factores determinan el éxito comercial de un título. Como analista de datos, el reto consiste en examinar la información disponible hasta 2016 para detectar patrones y variables clave que influyen en la popularidad y rentabilidad. Mediante análisis estadístico y exploración de datos, se busca comprender el impacto de cada factor en el desempeño de los juegos. Los hallazgos permitirán anticipar tendencias, priorizar proyectos con mayor potencial y diseñar estrategias publicitarias más efectivas para 2017.
