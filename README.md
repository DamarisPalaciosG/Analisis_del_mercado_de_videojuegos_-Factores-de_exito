El objetivo de este proyecto es realizar un análisis integral de la información histórica disponible de la tienda online Ice, especializada en la venta global de videojuegos. La empresa cuenta con datos provenientes de fuentes abiertas que incluyen reseñas de usuarios y expertos, géneros, plataformas y registros históricos de ventas; sin embargo, carece de un análisis estructurado que permita identificar qué factores determinan el éxito comercial de un título. Como analista de datos, el reto consiste en examinar la información disponible hasta 2016 para detectar patrones y variables clave que influyen en la popularidad y rentabilidad. Mediante análisis estadístico y exploración de datos, se busca comprender el impacto de cada factor en el desempeño de los juegos y, con base en los hallazgos, anticipar tendencias, priorizar proyectos con mayor potencial y diseñar estrategias publicitarias más efectivas para 2017.
